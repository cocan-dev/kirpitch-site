kirpitch.dev

Datasheets in. KiCad parts out.

kirpitch reads a component datasheet and builds the KiCad symbol, footprint, 3D model and SPICE model, so you can review them instead of drawing them. Open source.

Follow it on GitHub

In development. There is no release yet.

How it will work

  1. 01

    Read

    You give it a datasheet. It finds the pinout, the package and the electrical limits.

  2. 02

    Extract

    A language model pulls out the data, from any provider you choose, or none. Plain rules also work.

  3. 03

    Build

    Ordinary code draws the geometry. The model never draws a shape.

  4. 04

    Review

    You check the result after every stage, before anything reaches your library.

Targets KiCad 8, 9 and 10. Desktop app and command line.

About the name

From chirpici, the Romanian word for clay bricks. Small parts, made to be stacked. It also hides Ki(Cad) and pitch.
